# Study Bac zone — FrontEnd starter

واجهة أولية باستخدام Next.js App Router وReact وCSS.

## التشغيل على Termux

```bash
pkg update && pkg upgrade
pkg install nodejs-lts git
node -v
npm -v
```

إذا كان Node.js مثبتًا بالفعل، لا تحتاج إلى إعادة تثبيته.

```bash
cd Study-Bac-Zone
npm install
npm run dev
```

افتح في متصفح الهاتف:
`http://localhost:3000`

لإيقاف الخادم اضغط `CTRL + C`.

## ملاحظات مهمة

- المشروع FrontEnd تجريبي فقط.
- تسجيل الدخول والأكواد والامتحانات والنقاط ليست أنظمة حقيقية بعد.
- لا تضع كلمات مرور أو أكواد طلاب حقيقية في النسخة الحالية.
- لا توجد بوابة دفع.
- لا توجد مفاتيح API أو أسرار في ملفات الواجهة.
- صفحات الخصوصية وشروط الاستخدام نصوص أولية يجب مراجعتها قبل الإطلاق العام.
- يلزم Backend لتطبيق المصادقة والصلاحيات وحفظ النتائج والتحقق الحقيقي من الشهادات.
